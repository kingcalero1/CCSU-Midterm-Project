# MIS 310 Midterm Project

This project was created for the MIS 310 Spring 2026 midterm at Central Connecticut State University.

## Overview

This is a Python GUI application built using Tkinter. The program is designed to solve simple real-world tasks through an interactive interface. It also uses external data from a CSV file to display information when buttons are clicked.

## Features

### Project 1
- GUI-based application using Tkinter
- Displays and processes data through user input and buttons
- Includes multiple interactive features in one window

### Project 2 (Part 1 & Part 2)
- CCSU-themed GUI application
- Uses a CSV file (`examfile.csv`) to display:
  - Calendar information
  - Building data
  - Faculty data
- Additional features include:
  - School of Business information
  - MIS Department course list
- Buttons update output dynamically without overlapping results
- Styled interface with fixed window size and custom layout

## Files Included

- `main.py` → main Python program
- `examfile.csv` → data source for GUI outputs
- `logo.png` → CCSU logo used in the interface
- `README.md` → project overview
